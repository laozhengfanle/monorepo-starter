# 表格功能按钮规范（TableToolbar）

> 全站列表页表格 Card 的工具条按钮**必须**使用共享组件 `TableToolbar`
> （`apps/admin/src/shared/components/table-toolbar.tsx`），禁止手写散装 Dropdown / Button。
> 违反视为代码评审不通过。

## 一、按钮布局（固定顺序）

工具条统一为一行，顺序固定：

```
[额外按钮…]  [列控制]  [导出]  [刷新]
```

- **额外按钮**：页面主操作（如「新建账户」「新建角色」「新建菜单」「清空日志」），渲染在最**左侧**；
- **列控制**：Checkbox 下拉菜单（由 `useColumnControl` 提供），图标 `FilterOutlined`；
- **导出**：Excel / CSV 下拉菜单，图标 `DeliveredProcedureOutlined`；仅支持单一格式时渲染为单个图标按钮；
- **刷新**：`RedoOutlined` 图标按钮，重新拉取列表。

三个图标按钮均为纯图标按钮（无文字），必须带 `aria-label`（组件内置）。

## 二、组件 API

```tsx
<TableToolbar
  columnMenuItems={columnMenuItems} // useColumnControl 返回值；不传则隐藏列控制
  onExport={handleExport} // (format: 'excel' | 'csv') => void；不传则隐藏导出
  exportFormats={['excel', 'csv']} // 默认两者；只支持 CSV 传 ['csv']（渲染单个导出按钮）
  onRefresh={() => void refreshList()} // 刷新回调
  extra={
    canCreate && (
      <Button type="primary" icon={<PlusOutlined />}>
        新建账户
      </Button>
    )
  }
/>
```

### 参数说明

| 参数              | 类型                          | 必填 | 说明                                                      |
| ----------------- | ----------------------------- | ---- | --------------------------------------------------------- |
| `columnMenuItems` | `{ key, label }[]`            | 否   | `useColumnControl` 返回的列控制菜单项；不传隐藏列控制按钮 |
| `onExport`        | `(format) => void`            | 否   | 导出回调；不传隐藏导出按钮                                |
| `exportFormats`   | `('excel' \| 'csv')[]`        | 否   | 导出格式，默认 `['excel','csv']`；单格式时渲染单个按钮    |
| `onRefresh`       | `() => void \| Promise<void>` | 否   | 刷新回调；不传隐藏刷新按钮                                |
| `extra`           | `ReactNode`                   | 否   | 额外按钮（最左侧）                                        |

## 三、列控制 / 导出逻辑（useColumnControl）

`TableToolbar` 只负责渲染，逻辑仍由 `useColumnControl` hook 承载：

- 列控制：Checkbox 切换列显隐，**操作列（`key='actions'`）固定显示，至少保留一列**；
- 导出：只导出**可见列**（排除操作列），自定义列值走 `exportCell`，文件名「前缀_yyyyMMddHHmm」+ `.xls/.csv`；
- 已接入页面：账户管理 / 角色管理 / 菜单管理。

页面侧用法：

```tsx
const { columnMenuItems, columns, handleExport } =
  useColumnControl<TRow>({
    fullColumns,           // 全部列定义（含操作列，每列必须有唯一 key）
    initialVisibleKeys,    // 初始可见列 key
    exportFileNamePrefix,  // 导出文件名前缀（如「账户管理」）
    exportData,            // 当前筛选/过滤后的行
    exportCell,            // 可选：布尔/枚举/对象列 → 可读文本
  });

<Table columns={columns} ... />
<TableToolbar columnMenuItems={columnMenuItems} onExport={handleExport} onRefresh={...} />
```

## 四、三要素统一（所有表格页）

**表格功能按钮三要素：列控制 + 导出 + 刷新，任何列表页表格 Card 都必须三件齐全**，不允许只有导出/刷新的残缺工具栏。

- 列控制：`useColumnControl` 提供（操作列固定、至少保留一列），`columnMenuItems` 传给 TableToolbar；
- 导出：默认走 `useColumnControl.handleExport`（导可见列，Excel/CSV）；**受全局权限点 `global:data:export`（seed 全局权限分组「导出数据」，命名遵循 `{领域}:{实体}:{动作}`）控制**——TableToolbar 组件内置 `usePermission('global:data:export')` 检查，无权限自动隐藏导出按钮，页面无需各自判断；super_admin 隐式拥有；
- **例外（导出语义不同）**：审计日志导出是「按筛选条件拉全量」的服务端导出（`exportAuditLogs`），不是导当前页可见列——此时列控制照常接入，`onExport` 传页面自己的导出函数，`exportFormats={['csv']}` 渲染单个导出按钮；且受资源级权限 `config:audit:export` 与全局 `global:data:export` 双重控制（更敏感的导出可叠加资源级权限）；
- 导出文件名前缀 / 数据源是 `useColumnControl` 的可选参数（不传则 handleExport 不可用，页面自管导出）。

## 五、接入清单（现状）

| 页面     | 列控制 | 导出                   | 刷新 | 额外按钮         |
| -------- | ------ | ---------------------- | ---- | ---------------- |
| 账户管理 | ✅     | ✅ Excel/CSV（可见列） | ✅   | 新建账户（左侧） |
| 角色管理 | ✅     | ✅ Excel/CSV（可见列） | ✅   | 新建角色（左侧） |
| 菜单管理 | ✅     | ✅ Excel/CSV（可见列） | ✅   | 新建菜单（左侧） |
| 审计日志 | ✅     | ✅ CSV（服务端全量）   | ✅   | 清空日志（左侧） |
| 文件存储 | ✅     | ✅ Excel/CSV（可见列） | ✅   | —                |

新建列表页一律接入 `TableToolbar` 三件套，禁止复制旧写法。
