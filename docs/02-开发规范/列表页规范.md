# 列表页规范（搜索栏统一设计）

> 本仓库以「管理端列表 + 搜索」为最高频场景。**所有列表页的搜索栏必须一致**，由共享 `SearchBar` 组件承载。
> 本规范是 AGENTS.md / CLAUDE.md「前端页面规范」的落地详情，**任何 AI / 开发者新建或修改列表页前必读**。
> 核心原则：页面层**只声明字段配置，禁止手写散装搜索表单**，渲染全部交给 `SearchBar`。

---

## 1. 页面结构（两块 Card 上下排列）

```tsx
<div>
  {/* ① 搜索卡：独立的 Card，位于列表正上方 */}
  <SearchBar
    fields={searchFields}
    onSearch={handleSearch}
    onReset={handleReset}
  />

  {/* ② 列表卡：标题 + 工具条 + Table */}
  <Card
    title="账户列表"
    extra={<Space size="small">{/* 新建 / 列控制 / 导出 / 刷新 */}</Space>}
  >
    <Table ... />
  </Card>
</div>
```

**位置铁律**：

- 搜索栏 = 列表正上方的**独立 Card**（`SearchBar` 内部就是 Card，与列表 Card 间距 `marginBottom: 16` 已内置）。
- **禁止**把筛选表单嵌进表格 Card 内部（审计日志页旧写法为错误示范）。
- **禁止**手写 `<Form>` / `<Input>` / `<Select>` 拼搜索栏——一律用 `SearchBar` 组件。

---

## 2. 布局与宽度（SearchBar 内部实现，页面无需关心）

- **Row/Col 栅格**：字段、checkbox、按钮都是栅格项；控件 `style={{ width: '100%' }}` 填满列，天然等宽且响应式换行。
- **列宽**：`xs={24} sm={12} xl={6}`（桌面端一行 4 个）；`dateRange` 默认 `xl={8}`；字段可传 `span` 覆盖。
- **标签统一 72px**（`labelCol={{ flex: '0 0 72px' }}`），各输入框起始位置对齐。
- **checkbox 类字段**：独立栅格项（`xl=6`），空 label（72px）占位对齐；勾选文案用 `checkLabel`。
- **按钮区**：栅格流内排在**最后一个**（`xl=6`），空 label（72px）占位与 input 对齐、左对齐。
- 为什么必须给宽度：antd Select **没有默认宽度**（官方文档示例均显式设置 `width`），不设会收缩到最小宽度、选中值被截断成省略号（实测踩坑）；Input/DatePicker 虽有原生宽度，但栅格保证与 Select 等宽、布局整齐。

> **页面层禁止**设置 `style={{ width }}`：历史遗留的 160/180/200/260/280 等散装宽度全部删除。

---

## 3. 字段配置（页面只声明，渲染归 SearchBar）

页面通过 `fields: SearchField[]` 声明搜索字段：

```tsx
export interface SearchField {
  /** 表单字段名（提交 values 的 key） */
  name: string;
  /** 标签（label）。checkbox 字段传 ''（SearchBar 用空 label 占位对齐） */
  label: string;
  /** 控件类型 */
  type: 'input' | 'select' | 'dateRange' | 'checkbox';
  /** placeholder（input/select 用） */
  placeholder?: string;
  /** 输入框前缀图标（仅 input 且有搜索语义时用，如 SearchOutlined） */
  prefix?: ReactNode;
  /** Select 选项 */
  options?: { value: string; label: string }[];
  /** 默认值（initialValue，如缓存页 pattern 默认 "*"） */
  initialValue?: unknown;
  /** Checkbox 的勾选文案（type=checkbox 用） */
  checkLabel?: string;
  /** 栅格列宽（24 栅格）。默认 6；dateRange 默认 8 */
  span?: number;
}
```

控件约定（SearchBar 内部已统一，页面无需关心）：

- 输入类：`allowClear` + `placeholder="请输入…"` + `autoComplete="off"`；搜索语义（用户名/关键词/邮箱）加 `prefix={<SearchOutlined />}`。
- 选择类（Select / DatePicker）：`allowClear` + `placeholder="全部"`，**不加 prefix**。
- checkbox 类：`label: ''` + `checkLabel` 作为勾选文案（如「显示已删除」）。

---

## 4. 按钮（SearchBar 内部统一）

- **查询与重置都不带 icon**（视觉统一）：查询 `type="primary"` + `htmlType="submit"`，重置为普通按钮。
- 按钮是栅格流内最后一个，页面**无需**传按钮相关配置。

---

## 5. 重置语义（页面 onReset 必须遵守）

```tsx
const handleReset = (): void => {
  setPage(1); // 回到第一页
  setFilters({}); // 清空查询状态
  // SearchBar 已调用 form.resetFields()；清状态后由 useEffect 依赖驱动重新查询
};
```

- 重置 = `resetFields()`（SearchBar 已做）+ 清空查询状态 + `setPage(1)` + **重新触发查询**。
- **禁止**散装重置：`setKeyword('')`、`setFieldValue('pattern', '*')` 等写法一律不用——即使只有单个字段，也请走「清空整份查询状态 + 回第一页」的统一语义。

---

## 6. 查询触发（页面 onSearch 必须遵守）

- **点击「查询」才发请求**（筛选条件变化不自动请求）。
- `onSearch` 统一：

  ```tsx
  const handleSearch = (values: SearchValues) => {
    setPage(1); // 回第一页
    setFilters(normalize(values)); // 空值 → undefined
  };
  ```

- 请求由 `filters` / `page` 状态驱动（useEffect 依赖）。

---

## 7. 落地要求

- 新建列表页：**一律使用 `packages/shared/ui` 的 `SearchBar`**，通过 `fields` 配置声明，禁止手写散装 Form。
- 已有页面迁移状态：
  - admin-accounts / admin-roles / audit-logs / cache-admin ✅ 已迁移
  - admin-menus 为树形表格，可不使用搜索栏
- 修改 `SearchBar` 组件时，同步更新本文档 §2/§3/§4。

---

## 8. 检查清单（评审用）

- [ ] 搜索栏用 `<SearchBar>` 组件（无手写 Form / Input / Select 拼装）
- [ ] 搜索栏是列表上方独立 Card（间距 `marginBottom: 16` 由组件内置）
- [ ] 页面无散装 `style={{ width }}`
- [ ] 字段只声明配置：`placeholder` / `prefix`（仅 input 搜索语义）/ `options` / `initialValue` / `checkLabel`（checkbox）
- [ ] checkbox 类字段：`label: ''`，文案用 `checkLabel`
- [ ] 查询/重置按钮无 icon
- [ ] 重置 = 清空查询状态 + `setPage(1)` + 重新查询
- [ ] 点击「查询」才发请求

## 七、搜索栏 label 规范（全站强制）

- **SearchBar 的字段 label 一律不加冒号**（`Form` 已设 `colon={false}`，antd 默认会加"："——组件层已统一处理，页面无需也不得传带冒号的 label 文案）。
- 复选框类字段（`checkLabel`）与按钮区使用空 label 占位，同样无冒号。
- 任何手写表单（若存在）同样遵守：label 不带冒号。
